3Panel é um painel de controle open-source, moderno e baseado na web para gerenciamento de servidores Linux.

- **Gerenciamento Eficiente**: Por meio de uma interface gráfica web amigável, o 3Panel permite que os usuários gerenciem seus servidores Linux com facilidade. As principais funcionalidades incluem monitoramento de hosts, gerenciamento de arquivos, administração de bancos de dados e gerenciamento de containers.
- **Implantação Rápida de Sites**: Com integração profunda com o popular software open-source WordPress, o 3Panel simplifica o processo de vinculação de domínios e configuração de certificados SSL, tudo realizável com um único clique.
- **Loja de Aplicativos**: O 3Panel seleciona uma ampla gama de ferramentas e aplicativos open-source de alta qualidade, facilitando a instalação e atualização para seus usuários.
- **Segurança e Confiabilidade**: Ao utilizar práticas de containerização e implantação segura de aplicativos, o 3Panel minimiza a exposição a vulnerabilidades. A segurança é ainda aprimorada por meio da gestão integrada de firewall e auditoria de logs.
- **Backup e Restauração com um Clique**: A proteção de dados é simplificada com a funcionalidade de backup e restauração com um clique do 3Panel, que suporta várias soluções de armazenamento em nuvem para garantir a integridade e disponibilidade dos dados.

## Início Rápido

Execute o script abaixo e siga as instruções para instalar o 3Panel:

```bash
curl -sSL https://resource.3panel.pro/quick_start.sh -o quick_start.sh && bash quick_start.sh
```

Por favor, consulte nossa [documentação](https://docs.3panel.pro/quick_start/) para mais detalhes.
