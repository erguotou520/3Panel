# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| v1.x     | :white_check_mark: |

## Reporting a vulnerability

We first appreciate and are very thankful that you've found a vulnerability issue in 3Panel! By disclosing such issue to 3Panel development team you are helping 3Panel to become a much more safer project than before! ;)

To protect the existing users of 3Panel, we kindly ask you to not disclose the vulnerability to anyone except the 3Panel development team before a fix has been rolled out. Send an email to `security@3panel.pro` instead.
